# 术语口径

只收现场会用到、且容易说混的词。定义按车间说法，不按教材说法。

| 术语 | 现场口径 | 容易混成 |
|---|---|---|
| 定置 | 物品有固定位置，且有边界（线、框、架、格）能判超界 | 只把东西摆整齐；摆整齐没有边界，第二天就回不去 |
| 目视化 | 一眼能看出正常还是异常，不靠问人、不靠翻记录 | 贴了标签就算；标签写了但看不出超标，不算 |
| 在制品 | 已投入、未完工的件，含工位旁、工序间、待检、待转 | 只算堆在地上的；架上和箱里的同样是 |
| 必要缓冲 | 为吸收上下游节拍差、检验等待、批量转运而必须留的量 | 一看到堆积就判浪费 |
| 真浪费 | 超出必要缓冲的那部分，或本可不定置却长期无固定位 | 把所有在制品都算进去 |
| 超界 | 物品越过已划定的定置边界，越界多少可量 | 摆放不整齐；没有边界就无从判超界 |
| 落地 | 物品直接置于地面，无容器、无托盘、无架 | 有托盘但托盘落地，两者判法不同 |
| 容器规格 | 箱/托盘的容量与每件装量，决定一堆是多少件 | 只数箱数不折算件数 |
| 待检缓冲 | 检验前的等待区，有明确放行状态 | 无序堆积 |
| 前道过载 | 上游产出速度超过本工序消化能力，堆积只是结果 | 把堆积本身当原因，去划线了事 |
| 批量 | 一次投产或一次转运的件数 | 班产、日产 |
| 班产 | 一个班次实际合格产出 | 计划产量、设备标称产能 |
| 节拍 | 满足需求所需的单件产出间隔 | 实测循环时间；两者常不相等 |
| 循环时间 | 实际操作一遍花的时间，未标定视频只能做筛查 | 标准工时 |
| 换型 | 从上一品种合格件到下一品种首件合格之间的切换 | 只算调机时间 |
| 山积图 | 各工序作业时间与节拍的对比，需要完整工序表 | 看一眼工位排布就能画 |
| 超市 | 设定上限、按取用补充的受控存放点 | 普通堆放区 |
| 水蜘蛛 | 按固定路线与周期补料的人或车 | 临时叫人去搬 |
| 标准工位 | 位置、容器、数量、状态四样都有约定 | 只划了线 |

## 两处口径要咬死

- **批量和班产不是一个数**。批量说一次多少，班产说一班出多少。C 档追问里两个都要问，缺一个就定不了堆积是不是必要缓冲。
- **循环时间不等于节拍**。没有标定视频和真实产量，不写标准工时，也不拿抽帧推算的数当定额。
