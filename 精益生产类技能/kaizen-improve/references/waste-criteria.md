# 四类浪费判据

照片可判的有五类：5S 与定置、目视化、在制品堆积、通道与布局、堆码与堆垛。每类都写"算 / 不算 / 动手前必须补什么"。判据只用来归类，不能替代本现场的 A 档事实。

真浪费与必要缓冲的判定口径沿用 `kaizen-improve/references/countermeasure-rules.md`：能在一个节拍内消化掉的量是必要，超出的部分是浪费，没有节拍数据不下这条结论。本文件只负责归类，不另设口径。

## 1. 5S 与定置

**算**：有定置边界却超界；常用件无固定位；工具用完回不到原位；空容器、废料、私人物品混进作业区。

**不算**：东西整齐摆放但没有边界线，属于"目视化缺失"或"标准工位未定义"，不写成"物品乱放"；临时换型期间的暂放，若换型结束有归位约定，不算。

**必须先补**：这个位是不是该工位常用件、换型期间还是常态、有没有别的暂存区。

> 有边界才谈超界。没有边界就先判"缺标准工位"，别凭感觉说乱。

## 2. 目视化

**算**：数量上下限看不出来；合格/待检/待转状态分不出；异常发生无人能一眼发现；标识与实物不符。

**不算**：贴了标签但标签内容含糊，先归到"标识口径不清"；有看板但没更新，归到"维护失效"，不归到"没做目视化"。

**必须先补**：谁负责更新、多久更新一次、异常时谁响应。

> 判据是"看一眼能不能判断正常与否"，不是"墙上有没有东西"。

## 3. 在制品堆积

**算**：超出已设定的存放上限；同一工位旁出现品种或状态混放；堆积点没有任何上限约定；长期不动的件占了作业面。

**不算**：有明确上限、有放行状态、按批量转运形成的待检缓冲。这类堆积是必要缓冲，问题常在前道过载或检验能力，不在堆本身。

**必须先补**：批量、班产、箱子是空是满、上游是否连续供料、是否有检验等待、设定的存放上限是多少。

> 这一个画面能读出相反结论。C 档没补齐，只能写"待定性的堆积"，不写"库存浪费"。

## 4. 通道与布局

**算**：物品占用已划定的通道；消防、配电、门前被挡；通道宽度被容器或周转车吃掉；人车混行无分界。

**不算**：设备摆得近、排列整齐、朝向一致，这些只说明放在一起。不说明按工序排成一条流，也不说明有回流或搬运浪费。

**必须先补**：通道的设计宽度和实际余宽、这几台各做什么工序、半成品在半成品状态下实际沿什么路径走、是否跨区转运。

> 禁从"相邻"推"上下工序"，禁从"等距"推"连续流"，禁在缺工艺路线时谈搬运距离与回流。

## 5. 堆码与堆垛

**算**：同一托盘上零件朝向不统一（有的开口朝上、有的侧放、有的倒扣）；横竖交叉混放（长条形件有纵有横有斜）；端头参差、层间不对齐；件体突出托盘边缘悬空；堆叠不稳定有倾倒风险（交叉叠压、斜靠）；同区域不同托盘堆码状态差异大（说明能整齐但没标准）。

**不算**：件体尺寸超过托盘支撑范围导致的"必然突出"——这是容器规格不匹配，归到"容器与料架"类，不写成"堆码不整齐"；换型期间临时混放且当天清空的，归到"临时暂放"，不写成"堆码混乱"。

**必须先补**：件长范围（最小到最大）、托盘/料架规格、堆叠上限（几层）、搬运方式（叉车/人工/周转车）、当前有没有堆码标准。

> 堆码不整齐是"5S 与定置"的细化，但照片里堆码问题往往比定置线缺失更突出、更直接可判。判据是"同向、齐边、不突出、限高"四条，缺一条就算。

## 跨类的两条

- 先分真浪费与必要缓冲，再谈对策。分不出来就进 C 档，不硬判。
- 同一现象可能同时落两类（落地堆积既是无定置也是堆积），A 档按看到的事实记，不要为了归类删掉另一半。
