# CASE-003｜通道边的周转箱

来源：通用方法对照
浪费类型：通道与布局、在制品堆积
工序：转运
投入量级：1 / 3

【现场事实 A】
1. 通道内侧黄色边线内有 3 只周转箱，其中 1 只压线。
2. 通道其余段无阻挡，未见人车分界线。
3. 3 只箱无标签，看不出待转还是待检。

【当时补的数据 C】
1. 通道设计宽度与箱占之后的实际余宽。
2. 这 3 只箱是不是按固定周期补料的暂存点，有没有设定上限。
3. 是否处于转运车到达前的短时等待，等待多久。
4. 有没有别处可用的暂存区。

【判据】
按 `waste-criteria.md` 第 4 类判占道，第 3 类判堆积。两类要分开写，不能合并成一句"通道堆料"。压线属占道，无标签属目视化，箱数是否超标属堆积。

【B 档条件句】
1. 若压线导致通道余宽不足，则属占道，先清出通道，与箱里装什么无关。
2. 若 3 只箱是按周期补料、有上限且短时等待，则属必要缓冲，问题在暂存区位置没划，不在这批料。
3. 若无上限、长期不动且状态不明，则同时是真浪费与目视化缺失。

【对策】
1. 第 1 级：把暂存区边界划到黄线以外，依据 A1 压线；这条对策不依赖 C2、C3。
2. 第 2 级：补状态牌与存放上限，依据 A3。
3. 第 3 级：若 C1 显示余宽本来就不够，改容器尺寸或改暂存区位置，不动通道宽度。

【反例条件】
1. 若黄线本身划错、通道实际边界另有约定，第 1 级不成立，得先确认通道基准。
2. 缺 C1 时，不写"通道被堵"这类程度判断，只写"压线，余宽待量"。

【结果】
不适用。
