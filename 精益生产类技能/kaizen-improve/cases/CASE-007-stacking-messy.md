CASE-007｜钣金存放区堆码混乱：背景整齐前景交叉

来源：        通用方法对照
浪费类型：    5S与定置、在制品堆积
工序：        钣金
投入量级：    1 / 2 / 3

【现场事实 A】只写看得见的，带位置和数量
1. 前景和中景托盘上零件朝向不统一：有的开口朝上、有的侧放、有的倒扣
2. 中景区域长条形件（2.5-3.5m）有纵放、横放、斜放，形成交叉叠压
3. 零件端头参差，未对齐到托盘同一基准线，层间不对齐
4. 前景左侧和中景多处件体长度超出托盘（1.2m）支撑范围，悬空伸出
5. 背景远处蓝色托盘上框架类件层叠规整，无交叉无突出
6. 地面无定置线、无标识、无看板
7. 防护膜碎片散落地面至少 3 处

【当时补的数据 C】批量、班产、箱空满、供料方式、路径、约束
1. 待补：批量多少、班产多少
2. 待补：件长范围（最小到最大）
3. 待补：堆叠限高（几层）
4. 待补：搬运方式（叉车/人工/周转车）
5. 待补：该区域功能是工序间缓冲还是长期存放

【判据】引用 waste-criteria.md 的哪一类、哪一条
1. 第 1 类（5S 与定置）：无定置线、无标识、防护膜散落
2. 第 5 类（堆码与堆垛）：朝向不统一、横竖交叉、端头参差、突出托盘、堆叠不稳定
3. 关键对照：背景区整齐 vs 前景区混乱 → "能整齐但没标准"

【B 档条件句】若 X 成立则 Y，否则不算
1. 若件长差异大（2m 到 3.5m 混放）且托盘规格单一，则"突出托盘"是容器不匹配（归 3 级换料架），不是堆码不整齐
2. 若该区域是长期存放（件停留超一天），则无标识导致找料时间浪费，属于动作浪费
3. 若堆叠限高未定且交叉叠压，则倾倒风险是真实的（非假设），但具体概率需补 C 档

【对策】按 countermeasure-ladder.md 第几级，依据哪条 A
1. 1 级（依据 A1/A2/A3/A4）：统一朝向、消除交叉、收进托盘——当天可做，零投入
2. 2 级（依据 A1/A5）：托盘贴堆码标准卡（同向平行/端头齐线/不超托边/限高 X 层）——一周内
3. 3 级（依据 A4）：定制 2m×0.8m 长条料架（2 层带端挡）替代 1.2m 托盘——数周，需采购
4. 三件事必须一起做：摆整齐（治标）+ 定标准（治因）+ 换容器（治本）

【反例条件】什么情况下上面这条不成立
1. 若件长统一（都是 2m 左右）且托盘够大（1.5m+），则不需要换料架，1 级+2 级足够
2. 若该区域是临时换型暂放（当天清空），则堆码混乱是临时状态，不写改善
3. 若背景区"整齐"的托盘只是拍照前刚整理过（非常态），则"能整齐但没标准"的判断不成立

【结果】
不适用（通用方法对照）
