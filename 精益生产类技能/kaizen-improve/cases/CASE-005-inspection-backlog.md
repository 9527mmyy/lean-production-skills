# CASE-005｜待检区堆满了

来源：通用方法对照
浪费类型：在制品堆积
工序：检验
投入量级：4

【现场事实 A】
1. 待检区地面有 8 只周转箱，堆两层，箱子外形一致。
2. 区域有围栏和"待检"标牌，未见合格/不合格分区标识。
3. 工位旁有一张空白的放行状态表，未填写。

【当时补的数据 C】
1. 批量、班产、每箱装量。
2. 待检区设的上限是几箱、是否已超。
3. 检验点每班能放多少、有无排队。
4. 上游是否连续供料、有无前道产出节奏约定。
5. 8 只箱里有几只已检未放行。

【判据】
按 `waste-criteria.md` 第 3 类。有上限、有放行状态、按批量形成的等待属必要缓冲；已检未放行长期压着，或超出上限，才是真浪费。判据落在"上限"和"放行状态"，不落在箱数本身。

【B 档条件句】
1. 若 8 箱在上限内、状态可辨、检验点按班放行，则属必要缓冲，堆积不是问题。
2. 若检验能力低于上游产出且排队持续增长，则问题在前道过载或检验能力，改这堆料的摆放无效。
3. 若已有已检未放行的箱且无放行状态记录，则属目视化缺失兼放行流程卡滞，按第 2 类另记。

【对策】
1. 第 4 级：确认 C2、C3 后调整检验点位置或产出节奏，依据 A1 加 C 档数据，不依据箱数。
2. 第 2 级：补放行状态记录与合格/不合格分区，依据 A2、A3。

【反例条件】
1. 若当天是批量集中送检、次日集中放行，且这是既定转运约定，第 1 条判据要按约定上限重算。
2. 缺 C1、C2 任一项，不写"待检在制品过多"，也不给量化收益。

【结果】
不适用。
