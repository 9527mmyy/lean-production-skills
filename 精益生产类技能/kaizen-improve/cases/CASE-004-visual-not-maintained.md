# CASE-004｜有标线却看不出异常

来源：通用方法对照
浪费类型：目视化
工序：通用
投入量级：2

【现场事实 A】
1. 工位旁地面有黄色定置框，框内放着 2 只箱，框外紧挨着第 3 只箱。
2. 框旁立有一块数量看板，板面数字与现场箱数不一致。
3. 看板无更新日期，未见责任人栏。

【当时补的数据 C】
1. 看板由谁更新、多久更新一次。
2. 框的设定上限是几箱、上限依据是什么。
3. 框外第 3 只箱是刚到还是长期放着。
4. 异常时谁响应、怎么响应。

【判据】
按 `waste-criteria.md` 第 2 类。判据是看一眼能不能判断正常与否，不是墙上有没有东西。有看板但没更新，归"维护失效"；数字与实物不符，归"标识与实物不符"，两者都不写成"没做目视化"。

【B 档条件句】
1. 若看板有明确责任人和更新频次却未执行，则属维护失效，补牌子不解决。
2. 若框的上限就是 2 箱且第 3 只箱长期在外，则同时构成超界，按第 1 类判据另记一条 A 档。
3. 若上限从未定义，则"超界"无从谈起，先补的是标准工位约定，不是标签。

【对策】
1. 第 2 级：定看板责任人与更新频次，依据 A2、A3。
2. 第 1 级：确认上限后再判框外箱要不要归位，依据 A1；缺 C2 不做。

【反例条件】
1. 若看板数字记的是当班累计而非当前在库数，A2 的"不一致"是口径不同，不是失效。
2. 缺 C1、C2 时，不写"目视化做得差"，只写"数字与箱数不一致，口径待确认"。

【结果】
不适用。
