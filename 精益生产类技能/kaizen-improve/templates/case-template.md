# 案例模板

复制本文件建新案例，文件名 `CASE-NNN-短名.md`，编号连续不复用。字段不齐写"待补"，不猜、不补写。

**录入前先确认一条**：这份案例只能用于给 B 档条件句找前提、给 C 档追问定方向。案例不是现场证据，不能替代本现场的 A 档事实，也不许把案例结果搬到新现场。

```
CASE-NNN｜一句话标题

来源：        通用方法对照 / 自建现场记录（二选一，通用对照不写企业名）
浪费类型：    5S与定置 / 目视化 / 在制品堆积 / 通道与布局（可多选）
工序：        装配 / 机加 / 焊接 / 钎焊 / 布线 / 检验 / 转运 / 通用
投入量级：    1划线 / 2标识 / 3容器 / 4布局 / 5设备（可多选）

【现场事实 A】只写看得见的，带位置和数量
1.

【当时补的数据 C】批量、班产、箱空满、供料方式、路径、约束
1.

【判据】引用 waste-criteria.md 的哪一类、哪一条
1.

【B 档条件句】若 X 成立则 Y，否则不算
1.

【对策】按 countermeasure-ladder.md 第几级，依据哪条 A
1.

【反例条件】什么情况下上面这条不成立
1.

【结果】定性写，通用对照案例写"不适用"；不写量化收益、不写区间
```

## 建完要做的两件事

1. 更新 `cases/INDEX.md` 的三处索引（浪费类型、工序、投入量级），漏一处将来就检索不到。
2. 回头看"反例条件"是否和判据自洽。一个只有正例没有反例的案例，用起来必然套错现场。
