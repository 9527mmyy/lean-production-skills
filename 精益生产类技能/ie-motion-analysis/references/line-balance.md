# 产线平衡参考

Takt、产线平衡、SWCT、Yamazumi、Spaghetti、OEE、SMED、SLP。Step 6 扩展输出（产线平衡）必读。

---

## 1. Takt 时间

### 1.1 定义

Takt = 节拍时间 = 可用生产时间 / 需求数量

```
Takt (s) = 可用时间 (s) / 需求量 (件)
```

### 1.2 可用时间计算

| 项目 | 计算 |
|------|------|
| 班次时间 | 如 8h = 480 min = 28800 s |
| 计划停机 | 换班、会议、计划维护（从班次时间中扣除） |
| 非计划停机 | 用 OEE 的可用率数据估算 |
| **净可用时间** | 班次时间 - 计划停机 - 非计划停机估算 |

示例：8h 班次，换班 30min，计划维护 20min，非计划停机 10%：
```
净可用 = 480 - 30 - 20 - 480×0.10 = 382 min = 22920 s
Takt = 22920 / 需求量
```

### 1.3 注意

- Takt 从**需求**算，不从循环时间算（循环时间是现状，Takt 是目标）
- Takt 变化时（如订单量变化），重新计算所有下游指标
- 多产品共线时，算加权 Takt：Takt = 净可用时间 / Σ(各产品需求量)

## 2. 产线平衡（Line Balancing）

### 2.1 核心指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **产线效率** | Σ(各工位时间) / (工位数 × 瓶颈时间) | 目标 ≥85%，低于则检查优先序 |
| **瓶颈周期时间** | max(各工位时间) | 产线实际节拍 |
| **理论最少工位数** | Σ(各工位时间) / Takt | 向上取整 |
| **实际工位数** | 当前工位数 | 与理论最少对比 |
| **平衡损失** | 1 - 产线效率 | 目标 ≤15% |

### 2.2 工位分配（RPW / 最大候选规则）

1. 按工艺优先序（precedence）排列工序
2. 逐个工序分配到工位：
   - 当前工位累计时间 + 该工序时间 ≤ Takt（或瓶颈时间）→ 分配
   - 超过 → 开新工位
3. 优先序约束：前道工序必须在后道工序之前或同一工位
4. 同周期时间的工序，优先分配给当前累计时间最少的工位（RPW：Ranked Positional Weight）

### 2.3 平衡分析输出

| 工位 | 工序 | 时间 (s) | 累计 (s) | 利用率 | 瓶颈？ |
|------|------|----------|----------|--------|--------|
| 1 | 取料+定位 | 12.0 | 12.0 | 60% | |
| 2 | 折弯 | 15.0 | 27.0 | 75% | |
| 3 | 翻面 | 8.0 | 35.0 | 100% | **是** |
| 4 | 打磨 | 10.0 | 45.0 | 100% | **是** |
| | | | **45.0** | **88.9%** | |

## 3. SWCT（Standard Work Combination Table，标准工作组合表）

### 3.1 结构

横轴：时间（0 到 Takt，等分）
纵轴：活动类型（手动操作 / 自动（机器）/ 行走）

每个活动画在对应时间区间：
- 手动操作：实心矩形（操作员必须做）
- 自动（机器）：空心矩形（机器自动运行，操作员可离开）
- 行走：箭头线（操作员在移动）

### 3.2 关键检查

- **手动+行走的总和**是否 ≤ Takt？（操作员是否忙不过来）
- **机器自动时间**是否被操作员利用？（机器运行时操作员在做什么）
- **行走距离**是否可缩短？（与 Spaghetti 联动）

### 3.3 HTML 输出

用 SVG 画 SWCT：
- 横轴 0 到 Takt，等分刻度
- 三条泳道（手动/自动/行走）
- 每个活动矩形，标注活动名 + 时间
- 机器时间用空心，手动用实心，行走用箭头

## 4. Yamazumi 平衡图

### 4.1 结构

柱状图，每根柱子 = 一个工位，高度 = 工位时间
叠加一条水平线 = Takt（或瓶颈时间）

### 4.2 关键检查

- 超过 Takt 线的柱子 → 瓶颈工位（需要拆分或改善）
- 远低于 Takt 线的柱子 → 负荷不足（可以合并工位）
- 柱子间高低差异大 → 平衡差

### 4.3 HTML 输出

用 SVG 画柱状图：
- X 轴：工位编号
- Y 轴：时间 (s)
- 每根柱子标注工位时间
- 水平虚线 = Takt
- 超过 Takt 的柱子标红

## 5. Spaghetti 移动路径图

### 5.1 结构

平面图，标注：
- 设备位置
- 物料存放位置
- 操作员路径（从动作分析中提取的搬运路径）

### 5.2 关键检查

- 路径交叉点 → 碰撞风险
- 长距离搬运 → 布局不合理
- 路径总长度 → 与动作分析中的搬运距离对比

### 5.3 HTML 输出

用 SVG 画平面图：
- 设备用矩形标注
- 物料存放用圆圈标注
- 操作员路径用箭头线（标注距离）
- 交叉点用红点标注

## 6. OEE（设备综合效率）

### 6.1 公式

```
OEE = 可用率 × 性能率 × 合格率
```

| 指标 | 公式 | 目标 |
|------|------|------|
| 可用率 | 实际运行时间 / 计划运行时间 | ≥90% |
| 性能率 | (理想节拍 × 产量) / 实际运行时间 | ≥95% |
| 合格率 | 合格品数 / 总产量 | ≥99% |

### 6.2 六大损失

| 损失 | 类型 |
|------|------|
| 故障停机 | 可用率 |
| 换型/调机 | 可用率 |
| 缺料等待 | 可用率 |
| 空转/短停 | 性能率 |
| 速度降低 | 性能率 |
| 废品/返工 | 合格率 |

### 6.3 与动作分析联动

- 性能率 < 95% → 检查动作分析中的等待浪费
- 可用率 < 90% → 检查换型时间（SMED）
- 合格率 < 99% → 检查检查动作（I 符号）是否足够

## 7. SMED（快速换型）

### 7.1 内部/外部拆分

| 类型 | 定义 | 示例 |
|------|------|------|
| **内部换型**（Internal） | 必须停机才能做 | 装模具、调参数 |
| **外部换型**（External） | 不停机也能做 | 准备工具、预调模具、备料 |

### 7.2 改善三步

1. **识别**：记录当前换型全过程，标注每个步骤是内部还是外部
2. **转换**：能转为外部的内部步骤全部转外部（提前准备）
3. **缩短**：剩余内部步骤用并行化、标准化、工装化缩短

### 7.3 目标

- 换型时间缩短 50%+（典型）
- 终极目标：换型 < 10 min（SMED 10）

### 7.4 与动作分析联动

- 换型过程中的动作 → 用本技能的动作分析方法拆分
- 换型路径 → Spaghetti 图
- 换型等待 → SWCT 中的自动时间

## 8. SLP（Systematic Layout Planning，系统布局规划）

### 8.1 输入

- 产品-工序矩阵（每个产品经过哪些工序）
- 物料流量（工序间物料搬运量）
- 工艺优先序

### 8.2 输出

- 设施-设施关系图（哪些设施应该靠近）
- 布局方案（2-3 个候选）
- 与 Spaghetti 图对比（当前布局 vs 推荐布局的搬运距离）

### 8.3 注意

- SLP 是规划工具，不是改善工具——用于新线规划或大改造
- 小改善用 5S + 目视化 + 定点放置，不用 SLP

## 9. 学习曲线（Learning Curve）

### 9.1 公式

```
Y = a × X^(-b)
```

- Y = 第 X 件的单位时间
- a = 第 1 件的时间
- X = 累计产量
- b = 学习指数（学习率 80% → b = 0.301，学习率 90% → b = 0.152）

### 9.2 应用

- 新产品/新工艺的前 N 件时间会递减
- 标准工时应基于"熟练后"的水平（通常第 50-100 件）
- 学习曲线效应大的工序（如手工焊接），初期不要按标准工时考核

### 9.3 注意

- 学习曲线适用于重复性高的手工操作
- 自动化程度高的工序学习曲线效应小
- 不要对学习曲线效应大的工序用初期数据定标准
