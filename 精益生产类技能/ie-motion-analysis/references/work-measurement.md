秒表法、绩效评估、标准工时计算、工作抽样。Step 2.5 工时测量模块必读。

## 1. 秒表法（Stopwatch Method）

### 1.1 两种观测方式

| 方式 | 适用 | 操作 |
|------|------|------|
| **连续法**（Continuous） | 大多数作业 | 循环不停表，只在元素切换时读数并记录，表一直在走 |
| **回摆法**（Snapback） | 极短元素（<1s） | 每个元素独立启停，元素结束回零 |

- 连续法效率高，是默认选择
- 回摆法用于 <1s 的短元素，避免连续法读数误差过大
- 同一作业内可混用：长元素用连续法，短元素用回摆法

### 1.2 观测记录表

| 元素 | 循环1 | 循环2 | 循环3 | ... | 均值 | 评级 | 正常时间 |
|------|-------|-------|-------|-----|------|------|---------|
| 1. 取料 | 2.3 | 2.1 | 2.4 | | 2.27 | 95% | 2.16 |
| 2. 定位 | 1.8 | 1.6 | 1.7 | | 1.70 | 100% | 1.70 |
| ... | | | | | | | |

- 单位：秒（s），精确到 0.1s
- 循环数：由 Niebel N' 公式决定（§2）
- 机器节拍元素：只记实际时间，评级固定 100%（不评级）

### 1.3 异物（Outlier）处理

**排除标准**（满足其一即排除）：
1. 超出均值 ±3σ
2. 有可归因原因（设备卡料、中断、缺料、电话、人员离开等）

**排除规则**：
- 每条排除必须记录：原因 + 排除阈值 + 循环号
- 排除后重新计算均值和 σ
- 排除比例 >20% 时，提示操作员状态不稳定，需重新观测
- 不能"先算均值再挑掉不满意的"——必须在观测时同步记录原因

## 2. 最小循环数（Niebel N' 公式）

### 2.1 公式

```
N' = [(40 · √(N·Σx² − (Σx)²)) / Σx]²
```

- N = 已观测循环数
- x = 每个循环的时间
- Σx = 循环时间总和
- Σx² = 循环时间平方和
- 40 = 95% 置信度 × ±5% 精度的系数（其他置信度/精度组合见下表）

### 2.2 置信度/精度系数

| 置信度 | ±5% | ±10% | ±15% |
|--------|-----|------|------|
| 95% | 40 | 20 | 13 |
| 90% | 27 | 14 | 9 |
| 80% | 18 | 9 | 6 |

- 默认用 95% / ±5%（系数 40）
- 对标准时间不敏感的元素（如搬运），可放宽到 90% / ±10%（系数 20）

### 2.3 计算流程

1. 先测 10-20 个循环（pilot）
2. 用 pilot 数据算 N'
3. 如果 N' > 已观测数，继续观测到 N'
4. 如果 N' < 已观测数，停止观测
5. 对方差最大的元素单独算 N'（通常取时间最长的元素）

### 2.4 快速参考

- 变异小（σ/μ < 5%）：通常 15-25 个循环
- 变异中（5% < σ/μ < 15%）：通常 30-60 个循环
- 变异大（σ/μ > 15%）：通常 60+ 个循环

## 3. 绩效评估（Performance Rating）

### 3.1 Westinghouse 四维度

| 维度 | 说明 | 100% 标准 |
|------|------|----------|
| **技能**（Skill） | 操作者的熟练程度 | 熟练但不快的正常操作速度 |
| **努力**（Effort） | 操作者的工作投入程度 | 正常、持续的工作节奏 |
| **条件**（Conditions） | 工作环境（照明、温度、噪音等） | 标准工作条件 |
| **一致性**（Consistency） | 操作节奏的稳定性 | 平稳、无忽快忽慢 |

### 3.2 评级方法

- **逐元素评级**（必须）：每个元素单独评，不能整循环一个分
- 评级范围：60%-140%（超过 140% 提示动作设计有问题）
- 机器节拍元素：固定 100%，不评级
- 评级依据：观测员的主观判断（需经验），参考"正常速度"概念

### 3.3 评级记录格式

| 元素 | 评级 | 技能 | 努力 | 条件 | 一致性 | 理由 |
|------|------|------|------|------|--------|------|
| 1. 取料 | 95% | 95% | 100% | 100% | 95% | 熟练但取料位置偏远，节奏略慢 |
| 2. 定位 | 100% | 100% | 100% | 100% | 100% | 标准操作 |

## 4. 标准工时计算（OT → NT → ST）

### 4.1 公式链

```
OT（观测时间）= 保留循环均值（排除异物后）
NT（正常时间）= OT × 绩效评级（逐元素）
ST（标准时间）= NT × (1 + PFD 宽放)
```

### 4.2 宽放（Allowance）

| 宽放类型 | 典型值 | 说明 |
|---------|--------|------|
| 个人宽放（PFD） | 5%-15% | 喝水、上厕所、短暂休息 |
| 疲劳宽放 | 5%-15% | 体力劳动程度（轻/中/重） |
| 延迟宽放 | 2%-10% | 不可避免的中断（检查、调整） |
| **总 PFD** | **10%-25%** | 三者之和，按作业类型查表 |

- 轻体力（坐姿、精细操作）：10%-15%
- 中体力（站姿、一般操作）：15%-20%
- 重体力（搬运、重型操作）：20%-25%

### 4.3 计算示例

| 元素 | OT (s) | 评级 | NT (s) | PFD | ST (s) |
|------|--------|------|--------|-----|--------|
| 1. 取料 | 2.27 | 95% | 2.16 | 15% | 2.48 |
| 2. 定位 | 1.70 | 100% | 1.70 | 15% | 1.96 |
| 3. 折弯 | 5.00 | 100%（机器） | 5.00 | 15% | 5.75 |
| **合计** | **8.97** | | **8.86** | | **10.19** |

### 4.4 与现行标准对比

- 差异 = (ST - 现行标准) / 现行标准 × 100%
- 差异在 ±置信度范围内 → 标准合理
- 差异超出置信度 → 写差异报告（带数字），提交标准负责人
- 不替标准负责人做决策，只提供数据和建议

## 5. 工作抽样（Work Sampling）

### 5.1 适用场景

- 无法用秒表法（操作员走动、多任务、长周期）
- 验证宽放率是否合理
- 审计产线平衡

### 5.2 方法

1. 随机时刻拍照/记录（不提前通知）
2. 每次记录操作员在做什么（工作/走动/等待/休息）
3. 重复 N 次（N 由精度要求决定，通常 100-500 次）
4. 计算各类活动占比

### 5.3 精度计算

```
N = (z² · p · (1-p)) / d²
```

- z = 1.96（95% 置信度）
- p = 预估占比（没有预估时用 0.5，最保守）
- d = 允许误差（如 0.05 = ±5%）

示例：p=0.5, d=0.05 → N = (1.96² × 0.5 × 0.5) / 0.05² ≈ 384 次

### 5.4 结果报告

| 活动 | 次数 | 占比 | 置信区间（95%） |
|------|------|------|----------------|
| 操作 | 210 | 54.7% | [49.2%, 60.2%] |
| 走动 | 90 | 23.4% | [19.5%, 27.3%] |
| 等待 | 60 | 15.6% | [12.3%, 18.9%] |
| 休息 | 40 | 10.3% | [7.6%, 13.0%] |

## 6. PMTS 速查（预定动作时间标准）

PMTS（Predetermined Motion Time System）用于无法实测时的估算（如新设备、新工艺）。

### 6.1 MTM-1 基础动作时间（U = 0.129 s）

| 动作 | 代码 | 时间（U） |
|------|------|----------|
| 伸手 25cm | A2 | 1.5 |
| 伸手 50cm | A5 | 3.0 |
| 伸手 100cm | A10 | 6.0 |
| 抓取（简单） | G1 | 2.0 |
| 抓取（复杂） | G2 | 4.0 |
| 移动 25cm | M2 | 2.5 |
| 移动 50cm | M5 | 5.0 |
| 移动 100cm | M10 | 10.0 |
| 放置（简单） | P1 | 1.0 |
| 放置（复杂） | P2 | 3.0 |
| 转身 | T | 3.0 |
| 步行 1 步 | W | 3.0 |

### 6.2 估算流程

1. 分解动作到 MTM 基本元素
2. 查表得每个元素的 U 数
3. 总时间 = Σ(U) × 0.129 s
4. 加宽放得 ST

- PMTS 估算精度 ±10%-20%，用于可行性评估，不用于制定标准
- 有视频时用秒表法（实测），不用 PMTS

## 7. 交付物清单

工时测量模块的输出（追加到 HTML 报告中）：

1. **样本量验证**：N' 计算过程 + 是否充足
2. **观测记录表**：逐元素 × 逐循环时间
3. **异物排除日志**：排除的循环 + 原因 + 阈值
4. **绩效评估记录**：逐元素 Westinghouse 四维评级 + 理由
5. **标准工时计算**：OT → NT → ST 公式链 + 数值表
6. **工作抽样结果**（如适用）：活动占比 + 置信区间
7. **与现行标准对比**（如有）：差异 + 结论
